算法与数据结构笔记

一、复杂度与基础分析

1. 时间复杂度关注输入规模 n 增长时操作次数的量级，忽略常数和低阶项：
   O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(2^n) < O(n!)。
2. 空间复杂度包括额外开辟的数组、哈希表、递归调用栈。
3. 分析循环时看最内层语句执行次数；连续两个循环相加取大的量级；
   嵌套循环相乘；递归用递推式或递归树估算。
4. 经验值：1e8 次基本操作大约对应 1 秒，n 到 1e5 时 O(n^2) 基本会超时，
   应考虑 O(n log n) 或 O(n)。


二、数组与双指针

1. 数组在内存中连续存储，按下标访问 O(1)，中间插入删除 O(n)。
2. 双指针适用于有序数组或需要收缩区间的场景：
   对撞指针：左右两端向中间移动，如两数之和（有序数组）、验证回文串、反转数组；
   快慢指针：一个指针遍历、另一个记录写入位置或检测环，如删除重复元素、
   移动零、判断链表是否有环。
3. 两数之和（有序数组）示例：
   left, right = 0, len(nums) - 1
   while left < right:
       s = nums[left] + nums[right]
       if s == target:
           return [left, right]
       elif s < target:
           left += 1
       else:
           right -= 1
4. 三数之和可以固定一个数，再对剩余部分用双指针，注意跳过重复元素去重。
5. 双指针把暴力枚举的两层循环压缩成 O(n)，前提是能利用数组的有序性
   或单调性来排除不可能的分支。


三、滑动窗口

1. 用于求解「连续子数组/子串」满足某条件的最短或最长区间。
2. 模板：右指针扩张窗口，不满足条件时左指针收缩，过程中维护答案。
   left = 0
   for right in range(len(s)):
       更新窗口状态（加入 s[right]）
       while 窗口不满足条件:
           更新窗口状态（移出 s[left]）
           left += 1
       更新答案
3. 典型题：长度最小的子数组、无重复字符的最长子串、最小覆盖子串、
   最多包含 K 个不同字符的最长子串。
4. 窗口内状态常用哈希表计数、单调队列（求窗口最大值）、前缀和配合。
5. 关键点：窗口只能向右扩张和收缩，不能回退，所以每个元素最多进出窗口各一次，
   总复杂度 O(n)。


四、二分查找

1. 前提：查找区间必须有序，或具有单调性/可判定性（二分答案）。
2. 标准写法（左闭右开区间）：
   left, right = 0, len(nums)
   while left < right:
       mid = (left + right) // 2
       if nums[mid] < target:
           left = mid + 1
       else:
           right = mid
   return left if left < len(nums) and nums[left] == target else -1
3. 常见变体：查找第一个 >= target 的位置、最后一个 <= target 的位置、
   查找插入位置、旋转数组找最小值。
4. 边界问题的关键：想清楚区间是左闭右闭还是左闭右开，
   循环终止条件、mid 更新方式要与之配套，避免死循环。
5. 二分答案：当答案是单调的（例如「可行/不可行」随数值变化），
   可以二分枚举答案再写 check 函数验证。


五、哈希表

1. 哈希表平均 O(1) 查找、插入、删除；最坏 O(n)（大量哈希冲突）。
2. Python 的 dict 保持插入顺序，set 用于去重和快速成员判断。
3. 典型用法：两数之和（一次遍历记录补数下标）、字母异位词分组、
   最长连续序列、子数组和为 K、缓存（LRU 可用 dict 加双向链表实现）。
4. 注意哈希表的键必须可哈希（不可变类型）；自定义对象做键时
   要实现 __hash__ 和 __eq__。
5. 冲突处理：链地址法（每个桶挂链表）与开放地址法；
   Python 内部使用开放地址法，并会在负载因子过高时扩容。


六、链表

1. 单链表节点包含值和 next 指针；访问第 k 个元素 O(k)，头插 O(1)。
2. 常用技巧：
   虚拟头节点 dummy：简化删除头节点、合并链表的边界处理；
   快慢指针：找中点、判断环（快指针每次两步，相遇则有环）、
   找环入口（相遇后一个指针回头部，同步走再次相遇即入口）；
   三指针反转链表：prev / cur / nxt 逐段翻转。
3. 反转链表示例：
   prev, cur = None, head
   while cur:
       nxt = cur.next
       cur.next = prev
       prev, cur = cur, nxt
   return prev
4. 合并两个有序链表用双指针比较大小，接到 dummy 之后。


七、栈与队列

1. 栈后进先出，用于括号匹配、表达式求值、单调栈（下一个更大元素、
   柱状图中最大矩形）、递归转迭代。
2. 队列先进先出，用 collections.deque 实现，避免 list.pop(0) 的 O(n)。
3. 单调栈：维护一个从栈底到栈顶单调的序列，遇到破坏单调性的元素时
   出栈并结算答案，每个元素最多进出栈一次，总复杂度 O(n)。
4. 单调队列：常用 deque 维护滑动窗口最大值，队头保存最大值的下标，
   新元素入队前从队尾弹掉更小的值。


八、排序

1. 常见排序对比：
   冒泡/选择/插入排序 O(n^2)，插入排序在近乎有序时接近 O(n)；
   归并排序 O(n log n)，稳定，需要额外 O(n) 空间；
   快速排序平均 O(n log n)，最坏 O(n^2)，原地但非稳定；
   堆排序 O(n log n)，原地非稳定；
   计数排序/桶排序在值域有限时可达到线性时间。
2. Python 的 sorted 和 list.sort 用 Timsort，稳定，平均 O(n log n)，
   对部分有序数据有优化。
3. 多关键字排序：key 返回元组，或多次稳定排序按优先级从低到高排。
4. top-k 问题用大小为 k 的小顶堆，复杂度 O(n log k)。


九、递归与回溯

1. 递归三要素：终止条件、当前层处理、向下一层递归。
2. 回溯 = 递归 + 撤销选择，适合枚举所有组合/排列/子集/路径，
   模板：
   def backtrack(path, 选择列表):
       if 满足结束条件:
           记录结果
           return
       for 选择 in 选择列表:
           做出选择
           backtrack(path, 新选择列表)
           撤销选择
3. 剪枝：排序后跳过重复元素、提前判断剩余元素能否满足条件、
   限制搜索范围，减少无效分支。
4. 递归深度过大可能触发 RecursionError，可以改为显式栈或调整递归上限。


十、动态规划入门

1. 适用条件：问题可分解为重叠子问题，且满足最优子结构。
2. 步骤：定义状态（dp 数组含义）→ 写状态转移方程 → 确定初始值
   → 确定遍历顺序 → 返回结果。
3. 经典例子：
   爬楼梯：dp[i] = dp[i-1] + dp[i-2]；
   0-1 背包：dp[i][j] 前 i 件物品容量 j 的最大价值，
   逆序遍历容量实现一维数组优化；
   最长递增子序列：dp[i] 以 i 结尾的最长长度，
   可用二分加贪心优化到 O(n log n)；
   编辑距离：二维 dp 按字符相同/不同转移。
4. 记忆化搜索是自顶向下的写法，用字典或数组缓存已经算过的状态，
   写起来更直观，适合状态转移依赖不确定顺序的题。
5. 空间优化常把二维 dp 压缩成一维，注意遍历顺序保证依赖值不被覆盖。


十一、字符串与其他

1. 字符串不可变，频繁修改应先转换成列表再 join。
2. 常见题型：最长回文子串（中心扩展或 DP）、字符串相乘、
   字符串解码、单词拆分、KMP 模式匹配。
3. 位运算技巧：判断奇偶、取最低位 1（x & -x）、异或找只出现一次的数字、
   集合用整数位掩码表示状态。
4. 并查集用于连通性问题：路径压缩加按秩合并，近似 O(1)。
5. 图的基础：邻接表存储、DFS/BFS 遍历、拓扑排序（入度为 0 入队）、
   最短路径（Dijkstra 用小顶堆）。
6. 写题时先想清楚暴力解法及其复杂度，再看能否用有序性、哈希、
   单调性、空间换时间等角度优化。
