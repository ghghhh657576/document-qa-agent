# 离线评估脚本

三个脚本都**不需要 API Key**，只依赖 `requirements.txt` 里的分词与检索库，用来复现 README / 项目文档中的量化结论。

## 运行

在仓库根目录执行：

```bash
python eval/chunk_eval.py      # 切块质量：硬切 vs 标点感知切分
python eval/retrieval_eval.py  # 检索质量：top-1 / top-3 / MRR、大小写、语料外问题
python eval/citation_gate.py   # 引用兜底三条路径
```

## 各脚本看什么

| 脚本 | 指标 | 当前结果 |
|---|---|---|
| `chunk_eval.py` | 切块边界是否落在词中间；块数与长度分布 | n=500：朴素硬切边界切断率 41.1%（30/73）→ 标点感知 0.0%（0/70）；n=300：35.0%（43/123）→ 0.9%（1/114）；n=500 共 73 块，长度 min/中位/max = 10/517/593，无重复块 |
| `retrieval_eval.py` | 12 条标注问题的 top-1 / top-3 / MRR@3；大小写；语料外问题 | top-1 11/12（92%）、top-3 11/12、MRR@3 0.92；`BM25` 与 `bm25` 都命中 [24, 43]；未命中项是语义问法"怎么复用代码"（BM25 召不回"装饰器"那段，属已知限制） |
| `citation_gate.py` | 引用兜底三条路径 | 未检索且无引用 → 兜底话术（日志"已拦截"）；两次编造块号 → 兜底话术（日志"已重试过一次"）；正常检索 + 真实块号 → 放行；三条全部通过 |

## 边界与说明

- 数字依赖 `data/` 里的 3 份资料和默认切块参数 `n=500`；换数据或换参数，数字会变，脚本会直接打印新结果。
- 语料外问题不是全都能挡住：`retrieval_eval.py` 里"量子计算"仍召回 2 块，因为分词后的"计算"在语料里出现过。词汇粗筛只能过滤完全不搭边的问法，不能替代语义相关性判断。
- 延迟（3~6 s）、费用（¥0.007~0.013）、缓存命中率（22%~82%）依赖真实模型调用与调用历史，不属于离线可复现部分。
