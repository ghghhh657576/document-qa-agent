【Python 算法刷题清单（大二上 · 2026.9 ~ 2027.1）】

  用法：每天/隔天按顺序做一道，做完把 [ ] 改成 [x]。
  节奏：周一/三/五各一道，每道约 50 分钟。一学期 40 道。
  原则：跟着数据结构课的进度走，课上学什么就刷什么——这样课业和刷题互相加强。
  配套工具：python 算法训练.py syntax（语法速查）/ quiz（抽题）/ log（记录）/ stats（统计）

〖第 0 步：先补 Python 武器库（第 1~2 周，共 8 小时）〗

这是最优先的事。 你不补这个，刷题会事倍功半——因为你 80% 的时间会花在"这个操作用 Python 怎么写"而不是"这题怎么解"。
对照 python 算法训练.py syntax 逐个确认，会打勾：
· Counter / defaultdict —— 计数和分组（对应 C 的手写哈希表）
· deque —— 队列，popleft() 是 O(1)（不能用 list.pop(0)）
· heapq —— 优先队列 / Top-K
· bisect —— 二分查找（不用手写边界）
· 切片 —— [::-1] 反转、[i:j] 子数组
· 推导式 —— 尤其 [[0]*n for _ in range(m)] 建二维数组
· sort(key=lambda ...) —— 自定义排序（对应 C 的 qsort）
· enumerate / zip —— 同时遍历
验收：能不看资料写出上面 8 个的用法。

〖每周节奏（固定在日历里，不要"有空再刷"）〗

  时段 ｜ 做什么 ｜ 时长
  周一 ｜ 新题 1 道（六步法） ｜ 50 min
  周三 ｜ 新题 1 道 或 重做上周做不出的题 ｜ 50 min
  周五 ｜ 新题 1 道（六步法） ｜ 50 min
  周日 ｜ 当周 3 道题的合上重写抽 1 道 ｜ 20 min

六步法（每道题严格执行，见手册 4.4.1）：
    ① 自己想 15 min → ② 只看思路不看代码 → ③ 合上重写
    → ④ 三问自检（复杂度/边界/更 Python 的写法）→ ⑤ 记入日志 → ⑥ 三天后重做

〖一条最重要的提醒〗

  不要追求刷题数量，追求"看到新题能归类到模板"。
  学期结束时，如果你的 40 道题里有 30 道是"独立做出"的，这比你刷 150 道、大部分靠看题解要强得多。
  用 python 算法训练.py stats 盯着"独立做出比例"这个数字，而不是盯着总数。
