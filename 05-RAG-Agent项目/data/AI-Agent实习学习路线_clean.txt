【AI Agent 开发实习路线图（大二 → 大三暑期实习）】

  目标：用 12~14 个月，拿到 1~2 份有含金量的 AI Agent / 大模型应用开发实习，为大四秋招铺路。
  起点：C/C++ 熟练、数据结构在学、Python 会写脚本但不熟练、MySQL 基础、跟教程做过一个 AI 伴侣项目。
  已校准到每周 10 小时投入（学期内）＋ 寒暑假集中攻坚。时间不够时的砍单顺序见 6.2。

〖0. 先认清三件事〗

· 0.1 岗位到底要什么 ·

AI Agent 开发（也叫"大模型应用开发""LLM 应用工程"）不是算法岗，它更像后端工程师 + LLM 工具箱。社招/实习 JD 反复出现的词：
· Python 熟练（异步、类型注解、工程结构）
· 后端能力：FastAPI / Flask、REST、MySQL/PG、Redis、Docker
· RAG：向量库（Milvus / pgvector / FAISS）、Embedding、切分、召回重排
· Agent：Function Calling / Tool Use、MCP、多步规划、状态机、LangGraph / LlamaIndex
· 评测与可观测：Prompt 评测、Trace（Langfuse / LangSmith）、Token 成本与延迟优化
· 加分：微调（LoRA）、vLLM 推理部署、多模态、熟悉 Dify/Coze 之类平台
不要求你训练大模型，不要求你发论文。要求你能把模型接进真实系统并让它稳定工作。

· 0.2 你的时间窗口（按 2029 年 6 月毕业倒推） ·

  基准时间：2026 年 9 月，你正在读大二上。
  学期 / 时间 ｜ 阶段 ｜ 关键动作
  大二上（2026 秋）· 现在 ｜ 补基础 ｜ 图形学课设拿下 + 大物/模电保及格 + Python 工程化起步 + 算法 40 题
  大二寒假（2027.1~2） ｜ 补基础 ｜ FastAPI 打通 + 算法到 70 题
  大二下（2027 春） ｜ 项目期 ｜ AI 伴侣重写完成（异步 + 向量记忆 + 流式 + 评测数字）
  大二暑假（2027.7~8） ｜ 冲刺期 ｜ 做主力项目——你唯一有大块连续时间的假期，决定成败
  大三上（2027 秋） ｜ 投递期 ｜ 简历定稿 + 日常实习投递，寒假前拿到第一段实习
  大三下（2028 春） ｜ 决胜期 ｜ 暑期实习投递（2~4 月，转正率最高的通道）
  大三暑假（2028.7~8） ｜ 转化期 ｜ 实习转正 / 秋招提前批
  大四（2028 秋~2029 春） ｜ 收获期 ｜ 秋招 → 2029 年 6 月毕业

你有约 18 个月的准备时间。 比想象中宽松，但大二暑假那一格不能被动用——那是你大学期间最后一段能连续投入的大块时间。
最关键的认知：大三下的"暑期实习"是进大厂最稳的门（很多组暑期实习转正率 50%+）。它的筛选发生在 2028 年 2~4 月，也就是说你的项目和算法必须在 2028 年 3 月前全部准备好。往前倒推，主力项目最晚要在大二暑假（2027 年夏）结束时成型。

· 0.3 三个必须避开的坑 ·

1. 教程地狱：看完教程 ≠ 会。每学一个东西必须产出代码，且代码要能跑、能演示、有 README。
2. 框架收藏家：简历写 8 个框架，被问"你的 Agent 为什么用 LangGraph 而不是自己写状态机"答不上来，直接挂。深度 > 广度。
3. 放弃算法：笔试是硬门槛。AI Agent 岗算法难度通常低于纯后端/算法岗（多为 LeetCode 中等），但过不了笔试就没有后面。

〖1. 阶段一：Python 工程化（现在 ~ 第 6 周）〗

这不是"学 Python 语法"，语法你已经会了。目标是让 Python 成为你的第一语言。

· 1.1 必须真正掌握的东西（按优先级） ·

· 类型注解 + dataclass/Pydantic：Agent 项目里到处是结构化数据，Pydantic 是刚需
· async/await 与 asyncio：LLM 调用全是 IO 等待，异步是 Agent 性能的核心。搞清 async def / await / asyncio.gather / 并发限流 Semaphore，以及同步阻塞为什么会毁掉并发
· 装饰器与闭包：重试、计时、缓存、日志全靠它
· 生成器 / 迭代器：流式输出（streaming）就是生成器
· 上下文管理器 with：连接池、文件、锁
· 虚拟环境与依赖管理：venv + requirements.txt，进阶用 uv
· 异常处理与日志：logging 而不是 print
· 测试：pytest 写单测，Agent 项目尤其需要
· 项目结构：src/ 布局、模块拆分、配置用 .env + pydantic-settings

· 1.2 强制动作（不完成不许进阶段二） ·

  ⚠️ 已按 10 小时/周 裁剪，只保留真正必要的一项。FastAPI 服务推迟到阶段二，因为那时候有真实需求（AI 伴侣后端），学得更扎实。
· 唯一交付物：并发爬虫。100 个 URL，用 asyncio + aiohttp 抓取，带并发限制（Semaphore）、超时、指数退避重试、结构化日志、进度输出。
  · 这个练习一次性覆盖：异步、装饰器、异常处理、日志、类型注解。10 小时/周 ≈ 4 周完成（含踩坑时间）
  · 检验标准：把并发数从 10 调到 100，吞吐量为什么没涨 10 倍？能答出来说明你真懂了

· 1.3 时间成本（10 小时/周口径） ·

  任务 ｜ 预估时长 ｜ 周数
  异步 + 闭包/装饰器/生成器（边做爬虫边学） ｜ 15 h ｜ 1.5 周
  并发爬虫开发 + 调试 ｜ 20 h ｜ 2 周
  Pydantic + 类型注解 + 项目结构 + pytest ｜ 12 h ｜ 1.2 周
  数据结构课作业用 Python 重写（并行进行） ｜ 每周 1.5 h ｜ 贯穿
  缓冲/返工 ｜ — ｜ 1.3 周
  合计 ｜ 约 55 h ｜ 约 8 周（2 个月）

意味着：如果你现在（12 月）开始，阶段二要到明年 2 月才开始。这是 10 小时/周的真实代价，接受它，不要压缩这一步。

· 1.4 资源 ·

· 《流畅的 Python》(Fluent Python) —— 挑第 1、5、7、9、17、19、21 章精读，不要从头读到尾
· 官方文档：asyncio、FastAPI 的 Tutorial + Advanced 部分
· 练习平台：把 LeetCode 简单题全部换 Python 写一遍（见阶段四）
验收标准：给你一个陌生的 Python 项目，你能在 30 分钟内读懂它的目录结构、依赖、入口和数据流。

〖2. 阶段二：LLM 应用基础（第 7 ~ 14 周）〗

· 2.1 理论（够用就行，别陷进去） ·

· Token / 上下文窗口 / 温度 / top-p 到底是什么
· Transformer 与 Attention 的直觉（会用类比讲清楚即可，不推导公式）
· Embedding 是什么、为什么能算相似度、余弦距离
· 预训练 → SFT → RLHF 的大致流程（面试常问但只会问到概念层）
· 幻觉的成因和常见缓解手段

· 2.2 工程能力（重点） ·

· Prompt Engineering：不是玄学，是结构化。Few-shot、CoT、结构化输出（JSON Schema / function calling）、Prompt 模板化与版本管理
· Function Calling / Tool Use：这是 Agent 的地基。手写一遍不用框架的 tool call 循环
· RAG 全链路：文档解析 → 切分策略 → Embedding → 向量库 → 检索 → 重排 → 拼上下文 → 生成 → 引用溯源
· 向量数据库：先 FAISS 理解原理，再用 pgvector（复用你的 MySQL 直觉）或 Milvus/Chroma
· 流式响应：SSE，前端打字机效果
· 成本与延迟：Token 计数、缓存（精确缓存 + 语义缓存）、并发、模型分级路由

· 2.3 阶段项目 A：从"教程项目"升级为"我的项目" ·

把你现在的 AI 伴侣项目重写一遍（注意：是重写，不是改）：
· 后端换成 FastAPI + 异步
· 存 MySQL 或 PostgreSQL，会话/消息/用户三张表设计清楚
· 加向量记忆：长期记忆走 RAG，短期记忆走上下文窗口，实现"记忆检索 → 注入 prompt"
· 加流式输出 + 前端打字机
· 加 Docker Compose 一键启动
· 加一个简单的评测脚本：准备 30 条测试问题，用 LLM-as-judge 打分，能跑出准确率数字
为什么必须重写：面试官会问"这个项目你做了什么技术决策"。跟教程抄的项目答不了这个问题，重写过的答得上。

· 2.4 必读 ·

· Anthropic《Building effective agents》—— Agent 设计的经典文章，必读
· OpenAI / DeepSeek / Qwen 的 API 文档和 function calling 指南
· 论文挑着读：《Attention Is All You Need》《ReAct》《RAG》原始论文，读摘要+方法+结论即可

〖3. 阶段三：Agent 工程 + 主力项目（第 15 ~ 28 周，跨大二暑假）〗

这是整份路线里最重要的一段。你的目标是做出一个能让面试官追问 40 分钟的项目。

· 3.1 需要掌握 ·

· Agent 核心循环：ReAct、Plan-and-Execute、Reflection
· 状态管理：多轮、多工具、可中断、可恢复。"可恢复"很重要——生产级 Agent 要能持久化状态
· 多 Agent 协作：什么时候有用，什么时候是过度设计（面试常考的判断题）
· MCP (Model Context Protocol)：2025 年的重要标准，接工具/数据源。现在学是明显的加分项
· 框架：LangGraph（重点）、LlamaIndex、或 OpenAI Agents SDK。框架只能会一两个，但要懂它内部干了什么
· 评测体系：这是区分"玩具"和"工程"的分界线。Golden dataset、回归测试、指标（任务成功率、工具调用准确率、平均步数、Token 成本）
· 可观测性：Langfuse 或 LangSmith，做 Trace 可视化
· 工程化：限流、重试、降级、超时、Docker 部署、CI

· 3.2 主力项目选题（选一个做深，不要做三个做浅） ·

按"能不能讲出技术深度"排序，推荐从下面挑：
选题 A（推荐）：面向某个真实代码库的 Repository Agent
· 能读代码库、回答"这个函数在哪被调用""这个 bug 可能在哪"
· 工具集：文件读取、代码检索（AST + 向量混合检索）、执行测试、Git 历史查询
· 深度点：混合检索优于纯向量（能讲清楚为什么）、工具调用的错误恢复、多步推理的上下文管理
· 优势：能展示"我理解检索质量"，面试官是工程师，会聊得起来
选题 B：数据分析 Agent
· 自然语言 → SQL / Python 分析代码 → 图表 → 结论
· 深度点：SQL 生成的安全性（防注入、防删库）、执行失败自修复（错误信息回灌给模型重试）、结果校验
· 优势：业务感强，和你的 MySQL 基础接得上
选题 C：多工具个人助理 Agent
· 日历、邮件、搜索、笔记，带长期记忆和主动提醒
· 深度点：记忆的写入/遗忘策略、多工具冲突消解、权限控制

· 3.3 主力项目的"简历级"完成标准 ·

一个项目能让你拿到面试，必须同时具备：
· GitHub 仓库，README 写得像产品文档（截图/GIF、架构图、为什么这么设计、如何运行）
· 在线 Demo 或 3 分钟演示视频（面试官不会 clone 你的代码，但会看视频）
· 有评测数据：跑出过具体数字，比如"在 50 条测试集上任务成功率 82%，平均 3.2 步，单次成本 ¥0.04"
· 有优化对比：优化前 vs 优化后的数字（这是最有杀伤力的内容）
· 有 trace 截图：展示一次完整的 Agent 执行链路
· 想清楚 5 个问题：为什么用这个架构 / 遇到最大的 bug 是什么怎么解的 / 怎么评测 / 成本怎么控 / 如果流量涨 100 倍怎么改

· 3.4 时间分配建议（每周 15~20 小时，在校期间现实值） ·

· 大三上如果有课，保证：每周 5 小时算法 + 10 小时项目 + 2 小时读文档/论文

〖4. 阶段四：算法（贯穿全程，不能停）〗

· 4.1 现状与策略 ·

你现在的情况：C 语言解题熟、Python 不熟、数据结构刚在学。策略是：
· 主刷 Python，保留 C++ 作为第二语言。目标公司笔试多用 Python，但华为/部分硬件岗偏爱 C++。两把刀都磨，但 Python 是主刀
· 数量目标：大三下投递前累计 250~350 题（Hot 100 全部 + 代码随想录专题 + 剑指 Offer）
· 不要按题号顺序刷，按专题：数组/双指针 → 哈希 → 链表 → 栈队列 → 二叉树 → 回溯 → 贪心 → 动态规划 → 图论

· 4.2 节奏 ·

· 学期内：每天 1 题（30~45 分钟），不贪多，重在"每题都手写出来 + 能讲清复杂度"
· 假期：每天 3 题
· 每刷完一个专题，不看答案重写一遍，这是唯一有效的复习方式

· 4.3 数据结构课怎么用 ·

你正在学的数据结构是最好的算法训练。把课程作业全部用 Python 实现一遍（链表、树、图、排序、哈希表），一举两得：既完成课业，又练 Python。
加分动作：从零实现一个简易向量索引（暴力检索 + KD-Tree 或 HNSW 的原理版）。这直接连接你的算法能力和 AI 方向，面试时是很好的话题。

〖5. 阶段五：面试与投递（大三上开始）〗

· 5.0 ⭐ 什么时候可以开始找第一段实习？（最重要的判断） ·

答案：永远不要等"学完"。找实习不是毕业考试，没有及格线。

· 三个认知 ·

1. 实习是学习加速器，不是学习的终点。 你在实习里 2 个月的成长，大概率超过自学 6 个月。越早开始越好
2. "准备好了"永远不会到来。 你现在觉得"等我学完 RAG 就投"，学完 RAG 你会觉得"等我做完主力项目就投"。这个循环可以无限持续到毕业
3. 第一段实习的门槛比你想的低得多。 中小公司/创业公司招实习生，看的不是你懂多少，而是：能写 Python 吗？有项目能讲吗？能保证每周到岗几天？

· 三个投递档位（按你手上的"弹药"决定，不看知识完成度） ·

  你的现实约束（郑州 + 学期内仅 1~2 天到岗）会直接影响第一档怎么投，详见 5.4 节。
  档位 ｜ 时间 ｜ 触发条件（满足即投，不要犹豫） ｜ 目标
  试水档 ｜ 2026 年 12 月 ｜ ✅ 图形学课设能演示✅ 会写 Python 基础代码✅ 算法 40 题 ｜ 投 5~10 家"可远程"的 AI 创业公司练手（郑州本地 AI 岗极少，且你学期内只能到岗 1~2 天，远程是你的主战场）。挂了完全正常，目的是体验面试流程
  正式档 ｜ 2027 年 6 月 ｜ ✅ AI 伴侣重写版完成（能演示、有 README）✅ 能讲清 4~5 个技术决策✅ 算法 110 题✅ 后端基础八股过一遍 ｜ 认真投：一线城市暑期实习 + 远程日常实习。这是你第一段"有含金量"的实习
  冲刺档 ｜ 2027 年 9~12 月 ｜ ✅ 主力 Agent 项目完成（有 Demo + 评测数字）✅ 算法 180~220 题 ｜ 投大厂日常实习（全年滚动招聘），为 2028 暑期实习做铺垫

· "试水档"为什么重要（很多人忽略这点） ·

2026 年 12 月你可能觉得自己"什么都不会"，但请去投 5 家小公司。原因：
· 你会第一次知道面试真实的样子，这比看 20 篇面经有用
· 你会拿到一份"我到底哪里不行"的真实清单——这比你自己的猜测准确得多
· 万一中了，你大二就有实习经历了，后面所有事情都会顺很多
投递的成本几乎是零（改一份简历 + 半小时投递），收益却可能是"提前一年看清方向"。

· 判断"可以投了"的 5 条硬标准 ·

不用全部满足，满足 3 条 就可以开始投：
· 我能用 Python 独立写出一个小服务（哪怕很简单）
· 我有一个能演示的项目，且我能讲清里面 3 个技术决策
· 我能回答"进程线程区别""HTTP 是什么""数据库索引是什么"
· 我 LeetCode 简单题能独立做出来，中等题能做出一部分
· 我每周能保证 3 天以上到岗（或能接受远程）
注意：以上没有一条是"我学完了 XX 课程"或"我精通 XX 框架"。

· 什么时候确实应该再等等 ·

只有一种情况值得推迟：你连一个能演示的项目都没有。因为面试官只能通过项目判断你。所以优先级永远是：先做出一个能跑的东西，再投——而不是先学完所有知识再投。

· 5.1 面试考什么（AI Agent 岗典型结构） ·

1. 笔试：LeetCode 中等为主
2. 一面（技术基础）：Python 八股（async vs 线程、GIL、装饰器、深浅拷贝、生成器）+ 后端基础（HTTP、索引、事务、Redis 用途）
3. 二面（项目深挖）：你的 Agent 项目被逐层追问。这一轮决定成败
4. 三面/交叉面：RAG 原理、Agent 架构设计、场景题（"设计一个能查公司内部文档的问答系统"）
5. HR 面：动机、时间投入（实习每周能到岗几天，这个很实际，很多岗要求 4 天以上）

· 5.2 高频题（提前准备成"能讲 3 分钟"的答案） ·

· RAG 召回不准怎么办？（切分粒度、混合检索、重排、query 改写、HyDE）
· 如何评测一个 RAG / Agent 系统？
· Function Calling 的原理是什么？模型是怎么"决定"调用的？
· 多轮对话的上下文超了怎么办？
· 幻觉怎么缓解？
· Agent 陷入死循环怎么处理？
· 如何降低 Token 成本？
· 你的项目 QPS 是多少？瓶颈在哪？

· 5.3 投递策略 ·

· 第一份实习不要挑：中小 AI 公司 / 创业公司 / 学长内推，重点是"有实习经历"这四个字
· 渠道优先级：内推 > 官网 > 招聘 App。多混技术社区（GitHub、即刻、X、掘金），AI 圈内推很好拿
· 简历一页，项目占 60%，每个项目用 STAR + 数字 写
· 时间线：大三上（2027 年 10~12 月）开始投日常实习，大三下（2028 年 2~4 月）主攻暑期实习

· 5.4 ⭐ 投什么公司（基于"郑州 + 学期内仅 1~2 天"的现实约束） ·

· 5.4.1 先认清约束 ·

学校在郑州，学期内每周只能到岗 1~2 天。 这两个条件组合起来，决定了策略必须和一线城市学生完全不同：
  约束 ｜ 破解方式
  郑州 AI 研发岗位极少（产业结构以硬件代工、传统软件、政企信息化为主） ｜ 不要在郑州等机会，用远程 + 寒暑假异地
  学期内只能 1~2 天 ｜ 只投明确写"接受远程"或"接受兼职"的岗位，别投要求 4 天以上的（投了也过不了，浪费简历）
  大二、无实习经历 ｜ 用开源贡献替代实习经历（见 5.4.3，这是最被低估的通道）

郑州本地可关注（但都不是 AI 研发为主，作为练手或过渡）：汉威科技（传感器+AI 算法）、新开普（智慧校园）、UU 跑腿（本地互联网）、各大厂郑州分部（多为交付/销售，不是研发，谨慎）。

· 5.4.2 公司分层：好进程度 × 值不值得去 ·

  层级 ｜ 公司类型 ｜ 好进程度 ｜ 第一段实习推荐度
  第 1 层 ｜ AI 应用创业公司（10~100 人，做 AI 产品/Agent/SaaS） ｜ ⭐⭐⭐⭐⭐ ｜ 🥇 首选。门槛看能力不看流程，能碰真实全流程，决策快
  第 2 层 ｜ 成长期公司的 AI 团队（B/C 轮，已有产品） ｜ ⭐⭐⭐ ｜ 🥈 如果能进，优先选（有导师带 + 流程规范）
  第 3 层 ｜ 中小型软件公司的 AI 部门 ｜ ⭐⭐⭐⭐ ｜ 🥈 推荐，但 AI 含量可能不高
  第 4 层 ｜ 大厂外包 / 子公司 ｜ ⭐⭐⭐ ｜ 🥉 可以，但技术深度一般
  第 5 层 ｜ 大厂日常实习（字节/腾讯/阿里/美团/Kimi/智谱等） ｜ ⭐⭐ ｜ 攒够弹药再冲（见 5.4.5）
  第 6 层 ｜ 传统企业/国企 IT 部门 ｜ ⭐⭐⭐⭐ ｜ ❌ 对 AI Agent 方向几乎无帮助

为什么第一段选创业公司：不是因为它差所以好进，而是因为它对你现在这个阶段性价比最高——创始人直接面、门槛看项目不看学历、你能碰到核心功能，而大厂实习前两个月可能都在改 bug。
判断一家 AI 创业公司值不值得去：① 产品是不是真的在用（有用户/在线 Demo）② 技术负责人是不是技术出身 ③ 有没有人带你（问"入职后向谁汇报、谁带我"）④ 融资阶段。

· 5.4.3 ⭐ 开源贡献：你的隐藏通道（最推荐） ·

逻辑：AI 赛道大量项目在 GitHub 上开源，它们常年缺人但没有地理限制。
给一个 AI 项目提交高质量的 PR，效果等同于实习经历：
· 完全远程、时间自由 → 完美符合你"学期内只有 1~2 天"的约束
· 有公开记录 → 面试官能直接看你的代码，比简历可信
· 能认识维护者 → 而这些人往往就在你想去的公司里
· 大厂招人时确实会看 GitHub 活跃度
具体步骤：
1. 挑 2~3 个和你方向相关的活跃项目（RAG 框架、Agent 工具链、MCP 生态、向量库客户端）
2. 从 good first issue 标签开始，先做文档修正和小 bug
3. 做够 3~5 个 PR 后，认领功能开发
4. 和维护者熟了以后，直接问"你们公司招实习生吗"——转化率高得惊人
时间成本：每周 2~3 小时，正好吃掉你学期内的碎片余量。这项投入的回报率高于同期任何学习。

· 5.4.4 找远程实习：关键词与筛选铁律 ·

搜索关键词（BOSS 直聘 / 实习僧 / 即刻 / V2EX）：
    AI 应用 远程实习
    大模型 远程 实习生
    Agent 开发 远程
    Python 远程实习
    RAG 远程实习

筛选铁律：
· ✅ 有公开产品和官网（能查到、能试用）
· ✅ JD 里有具体技术栈（Python / FastAPI / RAG / LangChain 等）
· ✅ 面试有技术负责人参与（不是只有 HR 聊）
· ✅ 明确说清工作内容和汇报对象
· ❌ 不给补贴还要求全职——"远程实习"常被用来白嫖，一定问清是否有补助
· ❌ JD 全是"数据标注""数据清洗"且无开发内容——学不到东西，写进简历还减分
· ❌ 要你先交钱 / 买课 / 做"付费任务"——诈骗，直接拉黑
薪资参考：正规远程实习 100~200 元/天；一线城市日常实习 150~300 元/天；大厂日常实习 200~400 元/天。低于 100 元/天且工作量大要警惕。

· 5.4.5 按学期的投递计划（结合寒暑假的地理优势） ·

  时间 ｜ 在哪投 ｜ 投什么 ｜ 怎么解决到岗
  2026.12~2027.1 ｜ 远程为主 ｜ 远程实习练手 + 开源贡献起步 + 郑州本地小公司 ｜ 1~2 天/周正好，不冲突
  2027 寒假 ｜ 一线城市 ｜ 异地全职实习 4~6 周 ｜ 寒假时间完整，直接去北京/上海/深圳/杭州
  2027.4~6 ｜ 远程 + 本地 ｜ 远程实习续期 + 投暑假岗位 ｜ 学期内远程，暑假转全职
  2027 暑假 ｜ 一线城市 ｜ 主力实习（2~3 个月全职） ｜ 暑假全职，这是最重要的一段
  2027 秋起 ｜ 一线城市 ｜ 大厂日常实习（全年滚动招聘，不走暑期流程） ｜ 争取到岗 3 天，或谈远程

核心洞察：你的地理劣势只在学期内存在。寒暑假是你的地理优势窗口——直接去目标城市做全职，这是郑州学生最有效的打法。
另一个很多人不知道的通道：大厂"日常实习"是全年滚动招聘的，不走暑期实习那套流程。所以 2027 年 6 月你就可以投大厂日常实习，不必等到 2028 年。

· 5.4.6 渠道有效性排序 ·

  渠道 ｜ 有效性 ｜ 怎么用
  内推 ｜ ⭐⭐⭐⭐⭐ ｜ 牛客搜"内推"、GitHub 项目作者的招聘帖、即刻/X 上 AI 创业者的招人帖——留言附上项目链接，比简历管用 10 倍
  BOSS 直聘 ｜ ⭐⭐⭐⭐ ｜ 对实习生最友好，能直接和技术负责人聊。打招呼别用默认话术，直接写项目和技术栈
  技术社区 ｜ ⭐⭐⭐⭐ ｜ 即刻、V2EX、X、掘金、微信群——AI 圈内推多在这里流动
  学校/学长 ｜ ⭐⭐⭐⭐ ｜ 最容易拿但最容易被忽略。主动问师兄师姐"你们公司招实习生吗"
  实习僧 ｜ ⭐⭐⭐ ｜ 实习岗位集中，竞争激烈
  公司官网/公众号 ｜ ⭐⭐⭐ ｜ 大厂日常实习主要入口

一个高性价比动作：去 GitHub 搜你感兴趣的 AI 项目，看贡献者列表，找那些在国内创业公司的人。这类人通常愿意看一个认真提问的学生。成本几毛钱，回报可能是一段实习。

· 5.4.7 必须避开的坑 ·

  坑 ｜ 识别方法
  收费的"实习内推"中介 ｜ 任何要你交钱的直接拉黑，正规实习不收费
  纯数据标注岗 ｜ JD 写"数据标注/数据清洗"且无开发内容——学不到东西
  打着大厂旗号的外包 ｜ 问清"劳动合同签哪家公司""在哪个办公区"
  要求每周到岗 5 天连续 6 个月 ｜ 会直接毁掉课业。大二优先保证不挂科
  "AI 实习"实际是销售/运营 ｜ 看 JD 有没有具体技术栈，没有就是挂羊头

〖6. 每周节奏模板（10 小时/周口径）〗

· 6.1 时间块安排 ·

  时段 ｜ 内容 ｜ 时长
  周一 / 三 / 五 ｜ LeetCode 1 题（Python，45 min）—— 优先 Hot 100 ｜ 2.5 h
  周二 / 四 ｜ 项目开发（爬虫 → AI 伴侣重写） ｜ 2 h
  周六 ｜ 项目大块推进（唯一能"进状态"的时间块） ｜ 3 h
  周日 ｜ 理论学习（文档/论文/框架）+ 每周复盘 ｜ 1.5 h
  周日 ｜ 开源贡献（见 5.4.3）+ 远程实习 ｜ 1 h
  合计 ｜ 10 h

关于那 1 小时开源时间：这是本路线里投入产出比最高的一小时。因为你学校在郑州、学期内只能到岗 1~2 天，开源是你唯一不受地理和时间限制的"经历生产器"。哪怕一周只处理一个 issue、回复一条评论，坚持 6 个月后你在 GitHub 上的公开记录会比一份普通实习更有说服力。

· 6.2 时间不够时的砍单顺序（重要） ·

10 小时/周必然要做取舍。从下往上砍，上面的死也不砍：
1. 🔴 死保：把 AI 伴侣改造成"能讲清楚技术决策"的项目（见 3.3）
2. 🔴 死保：LeetCode Hot 100（每天 45 分钟）
3. 🔴 死保：每周 1 小时开源贡献（你的地理优势替代方案，见 5.4.3）
4. 🟡 保：主力项目（寒暑假集中做）
5. 🟡 保：RAG 全链路手写一遍（不用框架）
6. 🟢 可以砍：LangGraph / LlamaIndex 等框架（看懂即可，不必精通；面试问到时说"我手写过状态机，理解框架解决了什么"完全站得住）
7. 🟢 可以砍：论文精读（只读摘要 + 方法 + 结论，共 4 篇封顶）
8. ⚪ 直接放弃：向量数据库内部原理（HNSW 数学细节）、微调、vLLM 部署、多 Agent 协作、多模态
判断标准：每学一样东西前问自己——"这个东西我能在面试里讲 3 分钟，且简历上有一行对应的产出吗？" 答不上来就先别学。

· 6.3 每周复盘三问 ·

这周产出了什么可运行的东西？遇到什么卡点？下周最重要的一件事是什么？

〖7. 里程碑检查点（按 10 小时/周重算，含真实日历）〗

  时间点 ｜ 必须达成 ｜ 算法累计
  2026 年 12 月（大二上末） ｜ 图形学课设作品完成；大物/模电保及格；Python 异步/装饰器过一遍；投 5~10 家远程实习练手（见 5.0 试水档） ｜ 40 题
  2027 年 2 月（大二寒假末） ｜ FastAPI 打通能写 CRUD；项目骨架搭起来；寒假争取 4~6 周异地实习；开源贡献累计 3~5 个 PR（见 5.4.3） ｜ 70 题
  2027 年 6 月（大二下末） ｜ AI 伴侣重写完成：FastAPI 异步 + pgvector 长期记忆 + 流式输出 + 评测脚本能跑出准确率；简历第一版写好；开始投暑假实习 ｜ 110 题
  2027 年 8 月（大二暑假末） ｜ 主力项目（代码库问答 Agent 或数据分析 Agent）完成：Demo 视频 + 评测数字 + 优化前后对比 + trace 截图；暑假争取一线城市 2~3 个月全职实习 ｜ 180 题
  2027 年 11~12 月（大三上） ｜ 简历定稿 + 投递大厂日常实习（全年滚动招聘），拿到第一段有分量的实习 ｜ 220 题
  2028 年 2~3 月（大三下） ｜ 暑期实习投递就绪（这是决胜局） ｜ 260 题
  2028 年 7~8 月 ｜ 暑期实习转正 / 秋招提前批 ｜ 保持手感

注意 2027 年暑假这一格：连续 6~8 周、每周 30+ 小时，是你整个规划里唯一能做出主力项目的时间窗口。这个假期不能被旅行、其他课程项目挤占。如果被挤占了，退路是：把 AI 伴侣重写版打磨到主力项目的完成标准（补 Demo 视频、评测数据、优化对比），也能撑起简历。
如果暑假同时要实习又做项目：优先实习（真实经历不可替代），项目用晚上和周末推进，或把项目周期延到 2027 年 9~10 月。

〖9. 一句话总结〗

  Python 工程化是入场券，一个能被追问 40 分钟的 Agent 项目是通行证，算法及格线是门槛。三者缺一不可，顺序不能颠倒。
  每周只有 10 小时的人，赢在取舍而不是努力：手写 RAG 全链路 > 精通 8 个框架；一个完成度 100% 的项目 > 三个完成度 40% 的项目。
  学校在郑州、学期内只能到岗 1~2 天的人，赢在渠道而不是等待：学期内用开源贡献和远程实习攒弹药，寒暑假去一线城市收割。不要在郑州等机会。
